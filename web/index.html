    Words search the name and rules text. "exact phrase", /regex/. Terms are ANDed; or, ( ) and a leading - (not) combine them.

    t: typelegend, unit, spell, gear, battlefield, rune
    st: supertypechampion, signature, token, basic
    d: domaind:fury has Fury · d:fury,chaos has both · d=fury,chaos exactly · d<=fury,chaos playable in Fury/Chaos · d:colorless
    e m penergy, might, power: e<=3 m>=4 p=1 e:7+ (7 or more)
    a|bany of them, in any field: t:unit|gear d:fury|chaos e:1|2|3 kw:tank|shield for:jinx|viktor
    champ:champion (legend, champion units, signatures, cards with the tag) · champ="lee sin" exact · champ:(t:legend d:calm) champions with a card the query matches
    tag: o: kw:tag · rules text · keyword (kw:accelerate, kw:level)
    r: set: a: f: num:rarity · set (OGN, SFD, UNL, VEN, OPP…) · artist · flavour · collector number
    for:playable with a legend: within its domains (neutral cards always), only its own signatures, nothing banned · for:jinx for:"wuju bladesman" · for:(d:fury) any legend the query matches
    has:groups (with group:) that contain such a card: has:legend has:unit has:signature has:banned has:(t:legend d:fury); -has: for groups without
    is:the card: legend, champion (unit), signature, linked (belongs to a champion), banned, token · printings: alt, overnumbered, sigprint, promo, reprint · landscape
    sort:sort:domain,energy,-might,name — keys: name e m p type domain rarity set champion role
    group:champion, type, domain, set, rarity
    order:order of the groups: name, count, or a sort key of each group's first card (with group:champion: its legend) · group:champion order:domain,-count
    show:printingsevery printing as its own entry
    view:listor view:grid

    While typing, suggestions for fields and values: ↑/↓, Tab to take one. The filter bar under the search writes these terms into the query, so you can click a start and type the rest. / focuses the search. In the list, click a column to sort by it, shift-click to add it as the next key. Defaults are in web/settings.js.
